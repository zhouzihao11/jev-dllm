# 数据许可：私有纳入与公开审查分离

用户已授权将约 15.1 MiB 的 canonical 与冻结评测数据纳入现有私有仓库，11 份数据文件和 14 份来源卡片现已收录。该授权不等于第三方许可审查完成、公开仓库授权或统一的数据许可证。根 Apache-2.0 按文档适用于代码，不重新许可数据文本、标签、模型权重或来源卡片。

公开再分发前的逐来源审查仍未完成，尤其包括：

- Prompt Injection 捕获材料存在 Apache / CC BY 4.0 声明冲突，私有纳入和数据验证均未解决此冲突。
- AG News、DAIR Emotion 和 SST5 仍需核查具体来源及版本的条款。
- 其他来源仍需核查署名、相同方式共享、底层内容权利及适用通知义务。记录的许可证声明不是统一批准。

以上是审查状态说明，不是认定所有来源在法律上一律禁止再分发。公开前应完成适用条款与权利审查；目前保持仓库私有，helper 不改变仓库可见性。

捕获卡片和 [manifest.json](manifest.json) 元数据用于归属与复核，不是完整法律评估或穷尽的个人信息审计。详见[来源清单](SOURCES.md)及[第三方表](../THIRD_PARTY.md)。已完成的解压、字节比对和行数验证只证明相应数据准备结果，不扩大使用授权。模型权重、custom code/stub 和历史冻结代码 bundle 均未包含，其权利须独立核查。
