使用固定 JevBench v1.4.2 harness（revision
`1bcc55eb6c8cffde2306b3db03ede39b61c6152a`），目标协议 `jevbench::v1.4`。

- S1 在 231 条公开题上完成直接调用与 loopback HTTP 的全量一致性验证，最大差约 `1.39e-16`，无预测翻转。
- choice、noul、score、真实模型身份、别名、多问题独立推理、非法 schema/model 和超长拒绝均检查通过。
- 新服务进程通过原版官方 CLI 完成 231/231 次有效请求，没有失败、超长或重归一化。
- 结果仍为 **155/231、ACC 67.10%、10-bin ECE 14.25%、Brier 0.476916**，与原 HTTP 实验的质量指标完全相同。
- 延迟不要求逐次一致，没有用这次验证重新宣称加速。只跑公开题，未运行 sealed、申请排行榜或开启公网服务；服务退出后关闭。
