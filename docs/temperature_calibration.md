# S1 全局温度校准：Core14 与 Kev / Laya 比较

2026-10-09 完成的后处理实验。**全局温度 $T=1.8739716972345604$**，仅在固定六套旧 benchmark 上拟合，再应用到固定 Core14。权重、checkpoint、输入模板和原始 logits 不变。

本次发布的是结果与算法说明，**没有把研究用温度拟合/应用 CLI 迁移到公开仓库，也没有改变默认评测或 HTTP 的 T=1 行为**。本页校准后结果不能直接视为默认 quickstart 输出；原始未校准结果仍保留在[实验表](experiment_results.md)和[Kev 比较](kev_comparison.md)。

## 1. 固定模型、校准数据与目标

模型为 `Jev-DLLM-0.6B-S1`，原选择 dev KL 决定的 best（update 1300），公开 checkpoint revision 为 `1f1c29ff9fc6f6e9dc066b03089878a7dab8b6a0`。六套和 Core 都复用此前保存的 **BF16、batch32、旧 generic noul renderer、4096 上限**推理 logits；没有重新训练、模型选择或模型推理，也没有混入后来的 noul criteria 模板实验。

| 校准来源 | 决策数 | 本轮角色 |
|---|---:|---|
| typed-decisions | 2,000（400 个五问题 case） | 校准 |
| AG News | 7,600 | 校准 |
| Emotion | 2,000 | 校准 |
| Banking77 | 3,080，完整77候选 | 校准 |
| Prompt Injection | 116 | 校准 |
| SST5 | 2,210 | 校准 |
| 合计 | 17,006 | 六套等权拟合一个温度 |

这些文件原来是 legacy **test** 划分，本轮明确改作内部校准数据，并非另有六套预留 calibration/dev 划分。因而校准后的六套结果不是独立测试证据。没有混入 internal S0 test、checkpoint-selection dev、Core14 标签或 soft target 拟合。六套原来的 batch1 未校准结果也不能替代本轮 batch32 校准基线。

choice/score 沿用 shared Yes/No 分数，温度作用于最终决策 logits：

$$s_i=z_{i,\mathrm{Yes}}-z_{i,\mathrm{No}},\qquad p_i(T)=\operatorname{softmax}(s/T)_i.$$

noul 使用 $P_T(true)=\sigma((z_{\mathrm{Yes}}-z_{\mathrm{No}})/T)$，输出顺序为 `[false, true]`。所有套件和 primitive 共用同一温度，不增加类别偏置或任务专用参数。

拟合目标为六套等权 hard-label NLL，而非将17006条直接合并，避免 AG News 按样本量主导温度：

$$T^*=\arg\min_{T>0}\frac{1}{6}\sum_{d=1}^{6}\frac{1}{N_d}\sum_n-\log p_{d,n,y_{d,n}}(T).$$

采用 float64 的稳定 logsumexp、对逆温度 $\beta=1/T$ 的凸目标求解；检查零边界、括区间，再二分。优化 NLL 不截断概率，评分报告沿用既有 $10^{-12}$ NLL 下限。没有以 ECE 或 Core 结果选择温度。正式拟合进程只接收六套数据，保存温度后才启动正式 Core14 评分；smoke 拟合仅用于诊断。

| 拟合诊断 | 值 |
|---|---:|
| 全局温度 T | 1.8739716972345604 |
| 逆温度 beta | 0.5336259888426866 |
| 六套等权优化 NLL：T=1 | 1.2280664850 |
| 六套等权优化 NLL：T=T* | 1.0249981928 |
| 最优点导数 | 约 6.27e-12 |
| beta 最终括区间 | [0.5336259888135828, 0.5336259888717905] |
| 解的状态 | 有限正最优温度 |
| 校准集 argmax 变化 | 0 |

六套与 Core14 的规范化整段 state 精确匹配为0；规范化采用 NFKC、casefold、空白处理。六套内相同规范化 state + 完整 qdef 输入重复为0，typed 五问题 case 原样保留。这不是语义近重复或预训练污染证明。

## 2. Core14 同分母模型比较

Core14 是固定 Core17 去除 Kev 已确认训练来源 MultiNLI/Aegis2 和开发接触 PAWS后的14套，共 **5945 attempted**。来源限制沿用[Kev 比较](kev_comparison.md)：剩余项未确认重叠，不等于保证完全未见。

以下使用 base/S0/S1/Laya/Kev **共同成功的5690个相同 hard-target IDs**，ContractNLI 为1819条，其余13套全部成功。指标先按套计算再等权平均；不是 pooled ECE、官方 sealed 分数或综合排名。比较均沿用 ECE15、自然对数 NLL、类别平方误差和 Brier。

| 模型 / 固定协议 | 温度 | ACC ↑ % | ECE15 ↓ % | NLL ↓ | Brier(sum) ↓ |
|---|---:|---:|---:|---:|---:|
| S1，原始 BF16 batch32 | 1 | 63.97 | 14.92 | 0.9890 | 0.4851 |
| S1，同一 logits 全局校准 | 1.87397 | 63.97 | 10.33 | 0.8808 | 0.4637 |
| Kev-0.8B，原生 FP32 batch1 | 2.35110，checkpoint自带 | 60.31 | 14.30 | 0.9160 | 0.4921 |
| Laya-base，FP32 batch1 aligned_unit | 1 | 55.64 | 17.01 | 1.2423 | 0.5923 |

等套平均沿用历史报告中已舍入的子集指标。独立从逐条概率重算、不先舍入时，S1校准后共同集均值为 ACC63.9684%、ECE15 10.3314%、NLL0.88079567、Brier0.46371190；展示精度下结论一致。

| 校准后 S1 与对照逐套比较 | ECE更低 | NLL更低 | Brier更低 |
|---|---:|---:|---:|
| Kev-0.8B | 10/14 | 9/14 | 10/14 |
| Laya-base | 10/14 | 10/14 | 9/14 |

S1校准后的平均ECE相较Kev低3.97个百分点，相较Laya低6.68个百分点，平均NLL/Brier也更低。ACC没有因校准提升；正温度只改变概率。NLL/Brier同时受预测能力和校准影响，不能把模型间差异全部归因于校准或架构。

Laya这里是既定 **T=1 aligned_unit** 对照，没有在同六套数据上重新拟合温度；因此不是“最优校准后的Laya”。Kev使用其发布checkpoint已有温度，未在Core上拟合。

## 5. Score 诊断与结论边界

| 有 score 指标的六套等套平均 | 未校准 | 校准后 | 方向 |
|---|---:|---:|---|
| MAE ↓ | 0.807897 | 0.847684 | 退化 |
| RPS ↓ | 0.589401 | 0.545732 | 改善 |

以上六套包括JevBench original/hard、Jabr、HelpSteer2、SummEval relevance/consistency，只对有定义的score指标平均。hard NLL优化不保证期望评分MAE改善。例如SummEval consistency MAE0.658880→0.985835，relevance MAE0.843812→0.876318。

校准和Core的T1重构概率最大误差为0；全量Core14的5945个ID、status、原始logits保持不变，221条unsupported完整保留，argmax变化为0。独立标准库重算复现各套NLL/ECE/Brier/ACC，差异仅为原评分器四位小数舍入。smoke、全量拟合、全Core14评分均成功，本轮无失败尝试。

该结果支持**外部六套拟合的单一温度能改善Core14平均概率质量**，不支持所有任务、指标或分布全面改善。Core此前已被评估，本轮不是全新盲测；但没有使用Core标签拟合温度或在看到正式结果后重拟合。没有显著性检验、训练seed置信区间或匹配预算架构因果结论。JevBench行是Core旧renderer、batch32、ECE15数据集结果，不是较新的HTTP ECE10、sealed或官方排行榜校准轴。

固定模型、来源审计和历史对照协议见[Kev比较](kev_comparison.md)、[Core数据卡](../benchmark/DATA_CARD.md)和[训练说明](training.md)。本次公开提交只更新文档，不发布私有预测、日志、服务器路径或更改模型/运行默认值。
