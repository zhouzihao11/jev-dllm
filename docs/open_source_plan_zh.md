- 精选 S0/S1 builder、监督 trainer、评测器和实际导入依赖；保留 legacy helper 的结构，不重写训练框架。
- 增补[准备契约](data_and_models.md)、[canonical schema](SCHEMA.md)、[实际 CLI](reproduce.md)、[第三方表](../THIRD_PARTY.md)和[中文博客](blog_zh.md)。

不复制旧私有路径下载器、缓存依赖的冻结 bundle 准备工具、notebooks、发布 workflows、完整 raw 上游 train、权重、预测、token IDs、原报告、环境文件或 Git/worktree 元数据。私有数据只限明确白名单中的 canonical 和 fixtures；不改变外层工作树和原研究历史。
