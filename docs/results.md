# 结果与限制

以下为已完成研究运行报告的数值整理，不是此次发布目录的新运行结果。Core 和官方 JevBench HTTP 是两种不同协议，分别报告；发布版干净安装、来源重建与远程运行验证仍待补充。没有使用这些结果拟合温度或为本次公开集重新选择 checkpoint。

模型身份：base 为 [Qwen3-0.6B diffusion MDLM](https://huggingface.co/dllm-hub/Qwen3-0.6B-diffusion-mdlm-v0.1)，revision `c8d24a3f4adaeef46881b450e1bf7d1005203bd7`；[S0](https://huggingface.co/SEU-ZZH/Shared-YesNo-Qwen3-0.6B-S0) revision `265560cdcea68443fed89525437f4be7235574db`；[S1](https://huggingface.co/SEU-ZZH/Shared-YesNo-Qwen3-0.6B-S1) revision `1f1c29ff9fc6f6e9dc066b03089878a7dab8b6a0`。Laya-base 是继承的原生对照，不是另一份 S1。

## 官方 JevBench 公开 231 题 HTTP

上游 v1.4.2 固定 revision `1bcc55eb6c8cffde2306b3db03ede39b61c6152a`，协议 `jevbench::v1.4`。三模型均 BF16、batch 1、T=1、上限 4,096，通过 loopback 串行调用官方 CLI run/summarize。正式运行使用新服务、预加载权重，无预测 warmup。

| 模型 | 正确/总数 | ACC % | ECE10 % | Brier(sum) | NLL（补充） | HTTP mean ms | p50 ms | p95 ms |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| base | 135/231 | 58.44 | 12.97 | 0.595113 | 1.122264 | 49.80 | 38.19 | 100.69 |
| S0 | 142/231 | 61.47 | 13.19 | 0.468799 | 0.826951 | 49.47 | 38.02 | 99.66 |
| S1 | 155/231 | 67.10 | 14.25 | 0.476916 | 0.902037 | 48.56 | 36.66 | 98.70 |

ACC、ECE10、Brier、p50/p95 来自官方摘要；NLL 和 mean latency 为官方逐题结果的补充计算。ECE10 是 10 个等宽 bin，不是 Core ECE15，也不等于排行榜 Calibration 轴。不要把不同 batch、读出精度细节或 tie-breaking 下的 Core/HTTP 数值混用。

| 公开文件 | n | base ACC / ECE10 / Brier | S0 ACC / ECE10 / Brier | S1 ACC / ECE10 / Brier |
|---|---:|---:|---:|---:|
| easy | 48 | 100.00% / 12.15% / 0.0500 | 100.00% / 1.67% / 0.0029 | 100.00% / 0.74% / 0.0007 |

S1 总体准确率更高，但 ECE10 高于 base/S0，Brier/NLL 不如 S0；hard 准确率仍低于 base。easy 满分不能代表一般推理能力。

### 有效性与计时范围

- 历史验证中每模型 231/231 直接调用与 HTTP 概率一致，最大差不超过 `1.5e-16`，差异来自 noul 的 `1-p` 浮点末位；未出现预测翻转。
- 正式每模型 231/231 HTTP 200，严格分布有效；零失败、零超长、零重归一化、零未尝试，校准分母 231。
- HTTP 耗时包含本机请求、分词和推理，不是 GPU forward、官方德国网络测量或含权重加载的 cold start。几毫秒差异未经重复测量，不解释为稳定速度优劣。
- 模型成本未知；self-hosted 无可计费 API 预留不等于免费推理。没有调用 sealed、开放公网或提交官方排名。
- 接口等价不证明已理解所有 rubric：继承 noul prompt 不使用 criteria 描述。公开题已被观察过，不是盲测或对预训练无污染的证明。
